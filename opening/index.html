Research Projects

Reinforcement Learning in Partially Observable Stochastic Games

All Year Round

Preferred Qualifications: POMDP, Policy Optimization, Dynamic Programming in Markov (Stochastic) Games

Conventional reinforcement learning algorithms often assume perfect state observation, shared information, or centralized training. This project develops methods for individual agents to learn and make rational decisions under asymmetric information, addressing belief hierarchies and nonstationarity in partially observable stochastic games.

PhDRA

LLM Agent for Autonomous Cybersecurity

All Year Round

Preferred Qualifications: LLM Fine-tuning, RL Implementation, Network Security Basics

Reinforcement learning-based cyber agents can make autonomous security decisions, but often rely on simplified network models that do not capture real-world conditions. This project develops an LLM-enhanced agentic AI framework for security decision-making in computer and communication networks, with an emphasis on transparency, explainability, accountability, and minimal human intervention.
